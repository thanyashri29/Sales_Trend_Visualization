# Sales Trend Visualization

## Project Overview

This project analyzes sales data and presents meaningful insights using data visualization.

## Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit

## Features

- Total sales calculation
- Average sales calculation
- Best-selling product
- Best-performing region
- Sales trend analysis
- Product-wise sales analysis
- Region-wise sales analysis
- Category-wise sales distribution
- Monthly sales analysis
- Interactive dashboard
- Business insights

## How to Run

Install the required libraries:

pip install -r requirements.txt

Run the dashboard:

python -m streamlit run sales_dashboard.py

## Project Files

- sales_data.csv - Sales dataset
- sales_analysis.py - Data analysis
- sales_dashboard.py - Interactive dashboard
- requirements.txt - Required Python libraries
- README.md - Project documentation
