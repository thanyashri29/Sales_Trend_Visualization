# 📊 Sales Trend Visualization

## 📌 Project Overview

Sales Trend Visualization is a data analytics project developed using Python.

It analyzes sales data and presents meaningful insights through charts and an interactive Streamlit dashboard.

## 🎯 Objective

* Analyze sales performance
* Identify sales trends
* Find best-selling products
* Compare regional performance
* Analyze monthly and category-wise sales
* Present business insights visually

## ✨ Features

* Total Sales
* Average Sales
* Best-selling Product
* Best-performing Region
* Monthly Sales Analysis
* Product-wise Sales
* Region-wise Sales
* Category-wise Sales
* Sales Trend Visualization
* Interactive Dashboard
* Complete Sales Data Table
* Business Insights

## 🛠 Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Streamlit

## 📂 Project Structure

```text
Sales_Trend_Visualization/
│
├── sales_data.csv
├── sales_analysis.py
├── sales_dashboard.py
├── requirements.txt
├── index.html
└── README.md
```

## ⚙️ Installation

Install the required Python libraries:

```bash
python -m pip install -r requirements.txt
```

## ▶️ How to Run

Run the Streamlit dashboard:

```bash
python -m streamlit run sales_dashboard.py
```

## 📈 Dashboard

The dashboard provides interactive visualizations for sales trends, products, regions, categories, and monthly performance.

## 📊 Business Insights

This project helps understand sales performance and identify important business trends using data analysis and visualization.
