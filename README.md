# 📊 Sales Trend Visualization

## 📌 Project Overview

Sales Trend Visualization is a data analytics project developed using Python.
It analyzes sales data and presents meaningful insights through charts and
an interactive Streamlit dashboard.

## 🎯 Objective

- Analyze sales performance
- Identify sales trends
- Find best-selling products
- Compare regional performance
- Analyze monthly and category-wise sales
- Present business insights visually

## ✨ Features

- Total Sales
- Average Sales
- Best-selling Product
- Best-performing Region
- Monthly Sales Analysis
- Product-wise Sales
- Region-wise Sales
- Category-wise Sales
- Sales Trend Visualization
- Interactive Dashboard
- Complete Sales Data Table
- Business Insights

## 🛠 Technologies Used

- Python
- Pandas
- Matplotlib
- Seaborn
- Streamlit
